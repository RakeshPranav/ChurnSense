    How it works

    1

    Enter details

    The form is generated from the model's own feature schema, so it always matches training.

    2

    Pipeline runs

    Preprocessing and the classifier run as one saved pipeline, so nothing drifts out of sync.

    3

    Threshold decides

    The score is compared with a threshold chosen on out-of-fold predictions, not a default 0.5.
